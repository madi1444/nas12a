# Madiyar — визитка сайты

3D айналатын визитка (HTML + CSS + JavaScript).

## Өзгерту
`index.html` ішінде `your@email.com`, `@username`, `github.com/username` дегенді өз деректеріңізге ауыстырыңыз.

## GitHub Pages арқылы жариялау
1. GitHub-та жаңа репозиторий жасаңыз (Public).
2. `index.html` мен `README.md` файлдарын жүктеңіз (Add file → Upload files → Commit).
3. Settings → Pages → Source: «Deploy from a branch» → Branch: `main` / `(root)` → Save.
4. 1–2 минуттан кейін сайт `https://username.github.io/репозиторий-аты/` мекенжайында ашылады.
